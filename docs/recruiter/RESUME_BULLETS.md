## Data Analyst / BI roles

- Built a pharmaceutical sales and inventory dashboard with Python, SQL, Streamlit, and Plotly, analyzing 24 months of synthetic data across four Indian regions, 120 medicines, and 8,820 invoices.
- Implemented revenue, stock-at-risk, and inventory-turnover metrics with separate sale-line and batch facts; reconciled annual workbook KPIs against independent PostgreSQL queries and hand-verified fixtures.
- Developed a 33-rule data-quality framework across six dimensions, detecting 19 deliberate findings across 13 failing records and exposing quarantine evidence, review status, and validation history in Streamlit.

## Python Automation Engineer roles

- Built configurable daily and weekly reporting workflows with APScheduler, PostgreSQL execution history, idempotency keys, bounded worker subprocesses, retries, and concurrency protection.
- Automated seven-sheet Excel briefings with openpyxl, formatted tables, filters, conditional formatting, atomic writes, snapshot provenance, and checksum-verified downloads.
- Implemented low-stock, expiry, quality, and workflow-failure alerts with acknowledgment, resolution, revision tracking, and deduplicated notification preparation; added local email previews and mocked SMTP tests.

## Data Engineer roles

- Designed eight relational business tables with primary keys, foreign keys, composite warehouse constraints, checks, and indexes; generated and reconciled 44,365 deterministic synthetic records.
- Implemented transactional ingestion, versioned quality staging, audited corrections, and controlled approval that preserves existing business values; verified rollback with forced database failures.
- Containerized the application, PostgreSQL, scheduler, and authenticated local API with Docker Compose, persistent artifacts, health checks, and additive migrations; verified data and reports survived service restarts.

## Testing bullet usable across roles

- Verified the suite with 92 passing unit, dashboard, regression, and integration tests, including actual PostgreSQL transactions and independent SQL/Python KPI comparisons; checked code with Ruff.

## Short project description

Nivara is a locally runnable Python and PostgreSQL portfolio application that combines synthetic pharmaceutical distribution analytics, audited data-quality review, and scheduled Excel reporting. It emphasizes correct KPI calculations, traceable workflow execution, and safe local demonstrations.

## Claims to avoid

Do not claim measured time savings, reduced stock losses, production uptime, real MNC adoption, patient-data processing, FDA/GxP compliance, or commercial revenue generated by the project. The INR figures are synthetic dataset values. Real SMTP delivery and Microsoft Excel GUI were not tested; the source review also records an SMTP retry defect.
